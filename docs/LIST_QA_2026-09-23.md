# Bulleted list QA — September 23, 2026

Tested Markdown Live Preview on macOS, including the supplied photo's table,
heading, three nested bullet levels, and new bottom bullet.

## Fixes

- Nested lists inherited theme bottom padding in the middle of their parent
  list. Only outer list boundaries now receive list-edge spacing.
- Themes could add excessive bottom spacing to headings above lists. A compact
  heading-to-list gap now takes precedence, without removing source blank lines.
- Marker width varied with glyph size and font weight. Solid, hollow, and square
  markers now reserve equal-width boxes.
- Proportional fonts made literal indentation spaces too narrow to clearly
  separate levels. Leading list indentation now reserves character columns,
  preserving the actual spaces/tabs in the Markdown and copied source.

## Coverage

28 dedicated browser cases cover default, Obsidian Dark, and GitHub-like themes;
Editing and Locked modes; all six heading levels with/without a blank line;
three nested levels; sibling alignment and marker widths; `-`, `*`, `+`, and
task bullets; empty-item nesting; Shift+Tab at the root; multi-line selections;
four-space indentation; loose lists; and the supplied photo's layout.

A real VS Code test verifies Tab nesting, Return, Shift+Tab outdenting, and the
exact automatically saved Markdown bytes. Existing interaction tests cover
list continuation, Shift+Enter, repeated Enter to exit, selection, and clipboard.

Validation: 980 deterministic unit tests, 299 browser tests (including the 28
new list cases), and 20 focused desktop tests passed. The rebuilt VSIX passed
clean-profile trusted, restricted, and disabled-mode smoke checks. Screenshots
of the photo-style layout were visually reviewed after the spacing fixes.

These changes target the extension's Markdown Live Preview, not VS Code's
separate native Markdown Editor. This session does not constitute Windows/Linux
live testing or guarantee every custom CSS theme's layout.
